This repository contains the source code for my personal analytics portfolio — a collection of end-to-end data projects covering SQL, Python, business intelligence, and forecasting. Each project follows a consistent structure: business problem → data → analysis → insight → recommendation.

## Projects

### 01 — Sales Performance Dashboard ⭐ Featured
**Tools:** SQL · Python · Tableau · ETL

Built an executive dashboard tracking $24M in annual revenue across 6 product lines. Joined and cleaned 4 data sources, modeled in Python, and delivered in Tableau — reducing monthly reporting time from 3 days to 2 hours.

📁 [`projects/project-1/`](./projects/project-1/)

---

### 02 — Customer Churn Analysis
**Tools:** Python · Scikit-learn · Cohort Analysis

Identified the top 5 churn drivers for a SaaS business using cohort analysis and logistic regression. Findings directly informed a retention campaign that cut quarterly churn by 11%.

📁 [`projects/project-2/`](./projects/project-2/)

---

### 03 — E-Commerce Data Cleaning
**Tools:** SQL · Pandas · Data Quality

Wrangled a 500K-row retail dataset — resolved duplicate records, fixed currency inconsistencies, and standardized product categories across 12 regions. Every transformation is documented and reproducible.

📁 [`projects/project-3/`](./projects/project-3/)

---

### 04 — Demand Forecasting Model
**Tools:** Python · Facebook Prophet · ARIMA

Built a time-series forecasting model for a regional distributor. Reduced inventory overstock by 18% in one quarter by improving demand accuracy at the SKU level.

📁 [`projects/project-4/`](./projects/project-4/)

## Running Locally

No build step required — this is plain HTML/CSS/JS hosted via GitHub Pages.

```bash
git clone https://github.com/powellot/powellot.github.io
cd powellot.github.io
# Open index.html in your browser, or use a local server:
python -m http.server 8000
```

Then visit `http://localhost:8000`.
